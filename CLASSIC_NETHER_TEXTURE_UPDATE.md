# Classic Nether texture update

- The supplied textures from `New folder.zip` are now used by the Classic Nether blocks and lava.
- Added custom Classic Nether magma and quartz ore blocks.
- Classic Nether terrain uses custom netherrack and a custom flowing lava so modern Nether lava textures are not globally replaced.
- The VM destination is now named `Classic Nether`.
- Lost Reality now has a `lost_classic_nether` biome patch using the Classic Nether blocks/features and Alpha Ghast/Zombie Pigman spawns.
- Lost Reality's shared terrain generator keeps its existing generation system; the Classic Nether patch uses a netherrack surface and Nether-style features rather than replacing the entire Lost Reality terrain generator.
