# Classic Dimension Rework

- Classic dimension uses a 128-block-high world, matching the pre-Anvil/1.3-era world height.
- Classic terrain keeps the Classic stone/dirt/grass surface palette and legacy-style random terrain settings.
- Classic ore generation now uses Classic-era style distributions for coal, iron, gold, redstone, diamond and lapis, targeting Classic Stone.
- Classic Grass top/side and Classic Leaves were restored from the original Gallifrey.zip supplied at the start of the project.
- Classic Wool Windows have been removed completely.
- Classic Obsidian is accepted as a Nether portal frame in Classic and Classic Nether.
- Classic portal destinations remain Classic <-> Classic Nether at 1:1 coordinates.
- Classic Lava + water interaction produces Classic Obsidian for source lava, Classic Stone for stronger flowing lava, and Classic Cobblestone for weaker flowing lava.
- Existing Classic blocks retain their blockstate/model/item/loot-table data.
